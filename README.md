# マイスターの魔法陣 RPG（第1章・試作）

iPhone の Safari 向けのブラウザRPG。マイスターの塔のキャラクターたちが、錆に飲まれた「マイスターの塔」を1階ずつ登る。

- 遊ぶ：https://tnmtrt-pixel.github.io/mahoujin-rpg/
- バージョン：`index.html` の `const VERSION` を見る（タイトル画面にも表示）
- セーブ：各端末のブラウザに保存される（localStorage `mmrpg2`。0.2 までの `mmrpg1` は読みこんで引きつぐ）

## 遊び方のしくみ（0.3）

- 塔の中はサバイバー形式。出撃キャラを指で動かし、攻撃は自動。各階は1分以内に上への階段を見つける（ボス階はボスを倒す）
- 技ははじめは出撃キャラのものだけ。レベルアップで、持っているキャラ全員の技から選んで覚える
- パーティ（リーダーを入れて3人）は能力（パッシブ）で助ける
- 工房で「素材＋工具＋図面」をそろえて武器・防具をつくる。工具は武器にしない（武器は工具でつくる製品）
- ガチャでキャラを集める

## ファイル

- `index.html` … ゲーム本体（HTML・CSS・JavaScript を1ファイルにまとめたもの）
- `img/` … 画像（キャラ・敵・床・UIアイコンなど）
  - `img/ui/` … アイコン（素材・工具・武器・防具・攻撃の種類・属性・お知らせ・タブ・ランク）
  - `img/floor/` … 塔の床（下層・中層・上層）

## 更新のしかた

`index.html` と `img/` を差しかえて、`VERSION` の数字を上げてから main に入れる。GitHub Pages が自動で公開しなおす（1〜2分）。
